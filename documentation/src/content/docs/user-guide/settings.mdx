Settings contains device-level actions:

- `Exit to MiSTer` leaves MiSTer MagiK and returns to the stock MiSTer menu until reboot.
- `Controller Test` opens the live controller tester.
- `Simple joystick handling` toggles the simplified input policy.
- `Reset Database` deletes the library database, adjacent projections, screenshot pack state, recognized screenshot packs, and reboots.
- `Restart` reboots the MiSTer.

Database reset is intentionally broad enough to force a clean rebuild, but it should leave unrelated asset files alone.
