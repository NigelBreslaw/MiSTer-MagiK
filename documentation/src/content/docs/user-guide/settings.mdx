Settings contains device-level actions:

- `Exit to MiSTer` leaves MiSTer MagiK and returns to the stock MiSTer menu until reboot.
- `Controller Test` opens the live controller tester.
- `Simple joystick handling` toggles the simplified input policy.
- `Refresh Database` checks the filesystem watches and refreshes changed library systems in the background. Published games remain available, screenshot packs are preserved, and the MiSTer does not reboot.
- `Restart` reboots the MiSTer.

For attended destructive maintenance, run `mister-magik-fb purge-library-data --confirm`.
That command removes generated catalog artifacts, supported screenshot packs and their
sidecars/media state, reports separate removal counts, and does not reboot. It preserves
ROMs, configuration, saves, and unrelated assets. Without the exact `--confirm` argument,
it prints usage and changes nothing.
