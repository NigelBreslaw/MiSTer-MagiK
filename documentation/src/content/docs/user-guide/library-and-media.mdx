The library builder scans launchable content, classifies games, creates an in-memory catalog, then persists SQLite and adjacent warm-start projections. Cold first scan is foreground work because showing a usable catalog quickly matters more than perfect scan-screen animation.

```mermaid
stateDiagram-v2
  [*] --> LoadCache
  LoadCache --> ScanVisible: no usable DB
  LoadCache --> HomeVisible: warm summary or full DB
  ScanVisible --> Ready: RAM catalog usable
  Ready --> Persisting: save SQLite and projections
  HomeVisible --> BackgroundCheck: delayed validation
  BackgroundCheck --> Unchanged
  BackgroundCheck --> LibraryChanged
  LibraryChanged --> RebuildNow: user chooses Rebuild
  LibraryChanged --> RebuildNextBoot: user chooses Continue
```
