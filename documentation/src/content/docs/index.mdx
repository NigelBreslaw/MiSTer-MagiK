MiSTer MagiK is a Rust and Slint frontend for MiSTer FPGA. It is designed to make MiSTer feel like a polished launcher instead of a configuration project: quick game discovery, controller-friendly browsing, smooth arcade-style navigation, and reliable handoff into games.

```mermaid
flowchart LR
  Player["Player at the cabinet"] --> Launcher["MiSTer MagiK launcher"]
  Launcher --> Catalog["Game catalog"]
  Launcher --> Search["Search and filters"]
  Launcher --> Settings["Settings and controller tools"]
  Launcher --> Main["MiSTer_MagiK Main fork"]
  Main --> Core["MiSTer core launch"]
  Catalog --> Media["Screenshot packs"]
```
