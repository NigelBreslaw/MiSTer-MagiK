Canonical names:

- Product and UI text: `MiSTer MagiK`.
- Main fork binary, process, and device path: `MiSTer_MagiK`.
- Directory and script slug: `mister-magik`.
- Slint framebuffer binary and package: `mister-magik-fb`.
- Rust crate and import spelling: `mister_magik_fb`.

Where knowledge belongs:

- Agent-critical rules go in `AGENTS.md`.
- Current architecture goes in `docs/architecture.md` and is presented here.
- Device procedures and recovery go in `docs/device.md`.
- Benchmark method and scenario policy go in `docs/benchmarking.md`.
- Keep enduring decisions and unresolved work in the current owning document.
- Keep transient plans, status reports and measurement logs in ignored local
  artifacts or PR discussions. Superseded tracked narratives remain in Git
  history; use a commit-pinned link when exact historical evidence is needed.

The Starlight site should curate current truth. If a page discovers a policy gap, update the source policy document as part of the same change.
