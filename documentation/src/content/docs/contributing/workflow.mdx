Work in small, focused changes and preserve unrelated user work. The repository may already contain local edits, generated outputs, or private submodule state.

Useful host validation commands:

```bash
scripts/agent plan --working-tree
scripts/agent check --working-tree
scripts/agent verify --working-tree
scripts/agent check --paths apps/mister
scripts/agent verify --paths apps/mister
scripts/agent verify --paths mister/tools/host
```

For documentation work in this site:

```bash
cd documentation
corepack pnpm install
corepack pnpm build
corepack pnpm dev
```

Use `pnpm` 11 for the docs site. Keep generated screenshots under `documentation/public/screenshots/`.
