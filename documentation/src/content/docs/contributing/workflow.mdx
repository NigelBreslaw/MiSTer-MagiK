Work in small, focused changes and preserve unrelated user work. The repository may already contain local edits, generated outputs, or private submodule state.

Preview the full affected assurance plan without executing it:

```bash
scripts/agent plan
```

During Rust work, AI agents use the repository's bounded, lazy Rust analyzer
integration. Stage intentional paths and commit normally; pre-commit provides
the fast format, whitespace, policy, and shell-syntax gate. Pre-push and CI run
the full affected tests, builds, feature matrices, and policy checks.

For documentation work in this site:

```bash
cd documentation
corepack pnpm install
corepack pnpm build
corepack pnpm dev
```

Use `pnpm` 11 for the docs site. Keep generated screenshots under `documentation/public/screenshots/`.
