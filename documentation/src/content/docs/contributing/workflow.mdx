Work in small, focused changes and preserve unrelated user work. The repository may already contain local edits, generated outputs, or private submodule state.

Preview the local fast checks and CI-owned assurance without executing it:

```bash
scripts/agent plan
```

During Rust work, AI agents use the repository's bounded, lazy Rust analyzer
integration. Stage intentional paths and commit normally; the bootstrap-free
pre-commit hook provides the fast format, whitespace, policy, and shell-syntax
gate under a strict ten-second deadline. Pre-push runs the fast Python policy
checks plus Ruff format, Ruff lint, and Ty. CI runs Cargo, feature matrices,
pytest, ARM, and visual assurance.

For documentation work in this site:

```bash
cd documentation
corepack pnpm install
corepack pnpm build
corepack pnpm dev
```

Use `pnpm` 11 for the docs site. Keep generated screenshots under `documentation/public/screenshots/`.
