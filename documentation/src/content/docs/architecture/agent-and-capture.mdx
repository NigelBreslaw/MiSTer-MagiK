The Rust native service accepts authenticated, bounded requests and binary payloads
on TCP port `7500`. Desktop connects directly. Python host tooling provides device
discovery, deployment, testing and exceptional bootstrap or capability updates.
Compatible services remain installed across branches.

Authoritative screenshots use `capture-framebuffer`: the service reads the latched
scanout slot and returns RGB565 pixels with geometry and frame metadata. The
`scripts/magik mcp` adapter converts those pixels to an in-memory PNG and returns
base64 MCP image content directly to Codex. No raw `/dev/fb0` read is involved.

Desktop's live framebuffer stream relays application-produced frames, including
keyframes and deltas. It is distinct from authoritative still capture. Analytics
uses a separately owned, bounded subscription; disconnecting releases its lease.
