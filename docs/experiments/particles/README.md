# Particle experiments

The retained showcase code is available only through the explicit `experiments`
feature. Normal `ui` and `ui-preview` builds exclude its showcase modules and
recipes. Concept metadata and authored JSON recipes remain here; retired visual
acceptance checklists and image-generation prompts are available in Git history.

Current shared engine ownership, production scenes, development workflow and
qualification requirements are documented in [Shared framebuffer-scene
development](../../startup-particles.md). Licensed cabinet assets and attribution
remain under `crates/particles/assets/cabinet/`.
