# Retired alpha UI acceptance

`scripts/agent alpha accept` was removed with the legacy application UI harness.
It no longer produces an acceptance receipt. Development smoke, navigation and
profiling through [2.0](../magik2/README.md) do not qualify a published alpha,
physical controller input, HDMI capture, or Main/core return.

Production publication and candidate installation remain separate operations.
The explicitly attended `scripts/agent release qualify` and FPGA workflows keep
their own evidence requirements. No release gate silently substitutes the new
application scenarios for the removed UI journey. Historical alpha evidence is
historical only; it is not regenerated by a compatibility wrapper.
