# Host entrypoints

- `scripts/magik`: deployment, device/catalog control, Python scenarios, capture and benchmarks.
- `scripts/magik-platform`: platform/Main delivery and FPGA workflows.
- `scripts/magik-ci`: CI/releases, dependency maintenance, compile-time measurements and USB capture.
- `scripts/cargo`: Cargo with the shared worktree cache.

See [tooling usage](../magik/README.md) and [host utilities](../docs/host-orchestration.md).
Use `scripts/magik-ci guidance PATH` and `scripts/magik-ci plan` for ownership and validation.
